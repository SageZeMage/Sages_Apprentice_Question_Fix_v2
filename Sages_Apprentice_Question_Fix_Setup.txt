SAGES_APPRENTICE QUESTION-BIAS FIX
==================================

WHY IT WAS STUCK
----------------
Language Analyzer v2.1 has a structural question heuristic that strips an Apprentice address and then checks QuestionStartsTerms. Because that list contains "is", a declaration such as:

    Sage apprentice is a dirty clanker

becomes effectively:

    is a dirty clanker

and is marked as a question.

A second problem then magnifies that error: Attention Engine v1.2 treats saIsQuestion, behavior=question, OR broad question-like intents as questionLike, and its generic addressed_question fallback is late in the response-class chain.

Finally, Character Layer used sage_question as a broad fallback for almost every Sage question, so real questions about wellbeing, duty, or a prior answer all collapsed into the same response pool.

-----------------------------

2. Execute C#: existing Phase1 Guard Gate

4. Execute C#: SA - Observe Chat Pipeline v1.3.cs
5. Run Action: SA - Phase1 Trace

The main Observe Chat C# itself calls:
Language Analyzer -> early repair -> Context Engine -> Reply Bridge -> Persistent Learning -> Behavior Memory -> Session State -> Character Layer -> Attention Engine -> Response Brain
